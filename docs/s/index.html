Подставка для статуэток

Настройка один раз, минут на десять. Понадобятся телефон и Home Assistant.

  1. Включи подставку

    В розетку, через блок питания USB-C. Кольцо начнёт медленно дышать синим — подставка ждёт Wi-Fi.

  2. Подключи её к своему Wi-Fi

    Отсканируй камерой QR «1 · Wi-Fi» на наклейке. Телефон подключится к сети Figurki Setup и откроет страницу настройки. Выбери свою сеть, введи пароль, нажми Save.

    Страница не открылась сама — открой в браузере 192.168.4.1.

    Синее дыхание сменится янтарным: Wi-Fi есть, ждём Home Assistant.

  3. Добавь подставку в Home Assistant

    Настройки → Устройства и службы — там появится «Обнаружено: Статуэтки». Нажми Настроить и вставь ключ шифрования — его тебе передали вместе с подставкой.

    Не появилась — Добавить интеграцию → ESPHome, адрес figurki.local.

    Янтарное дыхание пропадёт — подставка на связи.

  4. Установи блупринт

    Это форма, в которой каждой статуэтке задаются цвет и сценарий.

    Добавить блупринт в Home Assistant

  5. Настрой статуэтки

    Настройки → Автоматизации → Создать автоматизацию → блупринт «Статуэтка → цвет и сценарий». Выбери статуэтку (номер на основании), цвет кольца, сколько секунд ему гореть, что сделать, когда статуэтку поставили и когда сняли. Сохрани.

    Одна автоматизация — одна статуэтка. Менять можно в любой момент, подставку трогать не нужно.

  6. Новая метка

    Подойдёт любая метка NTAG215. Поставь её на подставку — в Настройки → Метки появится новая запись. Скопируй её ID и впиши в поле «Статуэтка» вместо номера из списка.

Что показывает кольцо

Медленно дышит синим — нет Wi-Fi, шаг 2.
Дышит янтарным — нет связи с Home Assistant, шаг 3. Подсказка видна первые 15 минут после включения.
Загорелось белым — для этой метки ещё нет автоматизации, шаг 5.
